##Version Control Workflow

- Use branches for updates:  
  `git checkout -b update-ui`, `git checkout -b add-quiz-logic`
- Commit messages should be clear and descriptive:  
  `"Added new quiz screen"`, `"Linked Figma prototype in README"`
- Merge changes via Pull Requests to keep history clean
